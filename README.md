# QR Expiration Tracker Telegram Bot

Этот проект реализует Telegram-бота, который помогает отслеживать срок годности товаров на основе QR-кодов.
Пользователь сканирует QR-код на упаковке или добавляет продукт вручную, после чего бот сохраняет информацию и
напоминает о приближающемся окончании срока хранения.

## Возможности
- Приём данных из QR-кода в текстовом виде или с фотографии (при наличии Pillow + pyzbar).
- Автоматическое сохранение товара в базе данных SQLite на пользователя.
- Напоминания о скором истечении срока и уведомления о просроченных продуктах.
- Команда для ручного добавления, список товаров, удаление и очистка данных.
- Поддержка интеграции в раздел «Приложения» Telegram через настройку кнопки меню в BotFather.

## Требования
- Python 3.11 или новее.
- Установленный пакет [python-telegram-bot](https://docs.python-telegram-bot.org/) версии 20.
- Дополнительно для чтения QR-кодов с изображений: `pillow` и `pyzbar` (потребуется системная библиотека libzbar).

Пример установки зависимостей:

```bash
python -m venv .venv
source .venv/bin/activate
pip install python-telegram-bot==20.7 pillow pyzbar
```

Установка `pillow` и `pyzbar` необязательна, если планируется отправлять только текстовые значения QR-кодов.

## Конфигурация
1. Создайте нового бота через [@BotFather](https://t.me/botfather) и получите токен API.
2. Установите переменную окружения `TELEGRAM_API_TOKEN` с полученным токеном:
   ```bash
   export TELEGRAM_API_TOKEN="ваш_токен"
   ```
3. (Опционально) настройте параметры:
   - `PRODUCT_DB_PATH` — путь к файлу SQLite (по умолчанию `products.db`).
   - `EXPIRY_REMINDER_DAYS` — за сколько дней до истечения отправлять напоминание (по умолчанию 2 дня).
   - `EXPIRY_CHECK_INTERVAL` — период проверки напоминаний в секундах (по умолчанию 3600 секунд).

После настройки запустите бота:

```bash
python bot.py
```

## Работа с ботом
- Отправьте боту текст, считанный сканером QR-кода (Telegram сам подставит текст после сканирования).
- Чтобы добавить товар вручную, используйте команду `/manual "Название" 2024-05-01`.
- Просмотреть сохранённые позиции можно через `/list`, удалить — `/remove <ID>` или `/clear`.
- Бот автоматически напомнит о товарах, у которых подходит срок годности, и уведомит о просроченных.

## Добавление в раздел «Приложения» Telegram
Чтобы закрепить бота в разделе приложений/меню Telegram:
1. Откройте @BotFather → **Bot Settings** → **Menu Button**.
2. Укажите веб-приложение (если есть собственная веб-страница) или включите стандартное меню команд.
3. В диалоге с ботом нажмите «⋮» → **Добавить в приложения**, чтобы закрепить его в нижней панели Telegram.

Бот уже публикует набор команд через `set_my_commands`, поэтому после добавления он корректно отображается
в интерфейсе приложений Telegram и готов к дальнейшей интеграции с мини-приложениями.

## Безопасность
Токен Telegram не хранится в репозитории. Не забудьте отозвать ранее скомпрометированные токены через BotFather,
если они были опубликованы.
